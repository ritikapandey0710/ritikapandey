## Consent Required for Database Reset

To implement human-readable token IDs (like TKT-00001) in the Tickets page, we need to:
1. Add a `tokenNumber` column to the Token table in the database
2. Reset the database to apply this schema change
3. Reseed the database with 100 tokens (which will assign token numbers 1-100))

**Action:** `prisma migrate reset --force` followed by running the seed script

**What this will do:**
- Destroy all existing data in the PostgreSQL database (Table: Token, User, etc.)
- Recreate the database schema with the new `tokenNumber` column
- Reseed the database with 100 sample tokens (using the existing seed script)

**Important:** This action is **only safe for development databases**.
Since you just seeded the database for this task (as seen in the conversation history), this should be safe.
